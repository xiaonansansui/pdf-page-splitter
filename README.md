# 拆分PDF图片 · PDF page splitter

把 PDF 里每页的大图拆出来，存成 `1组.jpg`、`2组.jpg` ……，同时给每张图生成一张同名 A4 版 PDF；
还能把 PDF **压缩到指定大小**（方便发微信 / 传邮箱），以及**扫描并去掉软件加的红色水印**。

## 它做什么

双击后先选功能：

```
  ================================================================
   拆分PDF图片 v2.3    ·    作者: 小楠三岁    ·    @xiaonansansui
  ================================================================
     1   拆分 PDF      每页的大图拆成 jpg，并生成同名 A4 PDF
     2   压缩 PDF      把 PDF 压到你要的大小（比如 5 MB）
     3   去水印        先扫描并把水印标红给你看，确认后再去掉
     0   退出
  ================================================================
   请选择 1 / 2 / 3（输入 0 退出）:
```

| 能力 | 说明 |
| --- | --- |
| 拆出页面大图 | 只抽 PDF 里真正的页面图，跳过每页重复的页眉/水印模板图 |
| 生成 A4 PDF | 每张图再生成一页 A4 版 PDF，等比居中，四周留 14pt 边距 |
| **压缩体积** | 指定目标大小（如 5 MB），自动调质量/分辨率压到位；也支持一键自动压缩 |
| **去水印** | 先扫描、生成预览图把水印标红，你确认后再去掉；只处理红色水印 |
| 自定义文件名 | 输入 `n` 按菜单选：默认 / 用 PDF 名 / 自己起名字；也支持 `--name` 模板 |
| 零重压 | 原图是 JPEG 且不需要转正时，直接原样嵌入，不重新编码 |
| 自动转正 | 先按页面 `/Rotate` 转正，再按文字横向行特征纠正横躺的扫描件 |
| 批量 | 一次可以拖多个文件、整个文件夹，递归子目录 |
| 不闪退 | 处理完窗口留着，可以反复拖入，输入 `q` 才退出 |
| 打开目录 | 处理完询问“是否打开保存目录”，回车跳过、`y` 打开资源管理器 |

输出结构：

```
<PDF 所在目录>\拆分图片\
    └─ 构溪社区第一组会议纪要\
          1组.jpg   1组.pdf
          2组.jpg   2组.pdf
```

## 怎么用

### 方式一：双击 + 拖入（推荐）

双击 `拆分PDF图片.bat`，先输入 `1`（拆分）或 `2`（压缩）回车，再把 PDF 文件（或文件夹）拖进窗口，回车。

```
请选择 1 / 2（输入 0 退出）: 1

PDF: "C:\Users\me\Desktop\会议纪要.pdf"
```

窗口不会自己关，可以接着拖下一个；输入 `q` 回车退出，输入 `0` 回上一层菜单。
直接回车（或输入 `.`）= 处理 bat 所在目录里的所有 PDF。

### 方式二：拖到图标上

把 PDF / 文件夹直接拖到 `拆分PDF图片.bat` 的图标上，处理完窗口依然留着。

### 方式三：命令行

```bat
:: 拆分
拆分PDF图片.bat "文件或文件夹" [-o 输出目录] [--name 模板] [--jpg-only | --pdf-only] [--open | --no-open] [-nopause]

:: 压缩
拆分PDF图片.bat --compress [--target 5] "文件或文件夹"
```

| 参数 | 作用 |
| --- | --- |
| `-o 目录` | 指定输出根目录（默认是 `<PDF 目录>\拆分图片`） |
| `--name 模板` | 自定义输出文件名，见下一节 |
| `--compress` | 压缩模式 |
| `--target 5` | 压缩目标 5 MB；写 `auto` 或省略 = 自动压缩 |
| `--jpg-only` | 只出 jpg，不出 A4 PDF |
| `--pdf-only` | 只出 A4 PDF，不出 jpg |
| `--open` | 处理完直接打开保存目录，不询问 |
| `--no-open` | 处理完不询问、不打开 |
| `-nopause` | 跑完直接退出（脚本/计划任务用），不再进菜单 |

## 压缩 PDF 体积

首页菜单输入 `2`，然后填目标大小：

```
  ---------------------------------------------------------------
   压缩体积：把 PDF 压到你要的大小（单位 MB，1 MB = 1024 KB）
     · 直接回车    = 自动压缩（质量 75，长边 2480 像素，推荐）
     · 输入数字    = 尽量压到这个大小，例如 5
     · 输入 0 回车 = 返回上一层
  ---------------------------------------------------------------
   目标大小（MB）: 5
```

然后拖入 PDF，回车：

```
[构溪社区第一组会议纪要.pdf]
   原大小：1.85 MB
   试压 质量52 → 约 1.39 MB
   试压 质量26 → 约 0.98 MB
   压缩后：0.98 MB  →  构溪社区第一组会议纪要_压缩.pdf
```

* **只替换里面的图片**，页面、文字、书签、页面尺寸全部原样保留，不是把整份重排
* 压出来的文件放在**原 PDF 旁边**，叫 `原名_压缩.pdf`，不会动原文件
* 目标压不到时会自动降分辨率（85% → 70% → 55% → 45% → 35%）继续试，
  真到极限会告诉你实际是多大，并照样给文件
* 这份本来就很小、压不动时，会提示“新的反而略大，建议用原文件”

**不支持的情况**（会明确提示，不会硬压坏文件）：

* 纯文字版 PDF（里面没有大图，压不了）
* 加密 PDF
* 用了对象流 / 交叉引用流的新结构 PDF（多见于 Office 导出的电子版）

## 去水印

首页菜单输入 `3`，把 PDF 拖进来回车，程序**先只扫描、不动手**：

```
[水印测试.pdf]
   共 5 页，发现 1 个“每页都出现”的图片对象：
   · 238x81 像素，贴在 5 页上，位置在每页的 左下
   预览图：水印测试_水印预览.png（左边是页面，红框标出水印位置；右边是水印本身）
```

同时弹出预览图：左边是页面（红框标出水印位置），右边是水印本身。
看清楚再回答：

```
   右边这张图就是它找到的水印，确定要去掉它吗？
   （y = 去掉   n 或直接回车 = 不去）
   确认（y/n）: y
```

```
   已从 5 页里删掉水印对象（正文、文字、其他图片全部原样保留）
   输出：水印测试_去水印.pdf
```

**怎么判断的**：扫描软件加的水印有个固定特征——**每页都贴同一张图**。
程序按内容 md5 分组，找出“出现在 80% 以上页面、面积又远小于正文”的图片对象，
那就是水印（扫描全能王、某某扫描 App 的 logo 都是这种）。

**为什么无损**：不是在图片上涂抹，而是直接在 PDF 里把
`/X1 Do`（绘制指令）和 `/Resources /XObject` 里的引用删掉。
页面、文字、正文图片、印章**一个字节都不改**，输出和原文件大小几乎一样。

**做不到的情况**（会明确提示，不会乱改）：

* 水印已经烧进像素（扫描件上叠的浅灰字、彩色字），不是独立对象
* 加密 PDF、对象流结构的 PDF
* 水印本身很大（占到页面四分之一以上）时，程序不认它，避免误删正文图

> 说明：v2.4 早期版本里那个“红色像素涂抹”的做法已经去掉——那条路会伤到被红章
> 压住的笔画，而且容易把公章当水印误删。

## 自定义输出文件名

默认是 `1组.jpg`、`1组.pdf`。

### 最简单：跟着菜单选（推荐，不用记任何符号）

双击打开后，在 `PDF:` 后面输入 `n` 回车：

```
  ---------------------------------------------------------------
   输出文件名想怎么起？（以后拖进来的文件都用这个）
     1  默认              1组、2组、3组 ……
     2  用 PDF 的名字      会议纪要-1、会议纪要-2 ……   （推荐）
     3  自己起一个名字    比如输入“周例会”→“周例会-1”“周例会-2”
     0  不改，直接返回
  ---------------------------------------------------------------
   请输入 1 / 2 / 3（0 返回）:
```

选 3 之后直接打字输入想要的名字，回车即可：

```
   请输入名字（例如 周例会），直接回车 = 取消: 周例会

文件名已设置：如 周例会-1.jpg、周例会-2.jpg ……
```

之后拖进来的 PDF 都用这套名字，菜单顶部会显示当前用的是哪一种：

```
   当前输出文件名：原PDF名+序号，如 会议纪要-1、会议纪要-2 ……
```

### 进阶：命令行模板（`--name`）

给一个模板就能完全自定义，模板里只写名字也可以——**没写占位符时会自动在后面补序号**：

```bat
拆分PDF图片.bat "会议纪要.pdf" --name "周例会"
::  周例会-1.jpg / 周例会-1.pdf / 周例会-2.jpg ...

拆分PDF图片.bat "会议纪要.pdf" --name "{pdf}-第{page}页"
::  会议纪要-第1页.jpg ...
```

| 占位符 | 含义 | 例（序号 2、原页码 2） |
| --- | --- | --- |
| `{n}` | 图片序号，从 1 开始 | `2` |
| `{nn}` | 序号补零到两位 | `02` |
| `{nnn}` | 序号补零到三位 | `002` |
| `{page}` | 图片在原 PDF 里的页码 | `2` |
| `{pdf}` | 原 PDF 文件名（不含扩展名） | `构溪社区第一组会议纪要` |
| `{date}` | 今天日期 | `20261124` |

```bat
拆分PDF图片.bat "会议纪要.pdf" --name "会议纪要-{n}"
::  会议纪要-1.jpg / 会议纪要-1.pdf / 会议纪要-2.jpg ...

拆分PDF图片.bat "会议纪要.pdf" --name "{pdf}-第{page}页"
::  构溪社区第一组会议纪要-第1页.jpg ...

拆分PDF图片.bat "会议纪要.pdf" --name="{date}-{nn}"
::  20261124-01.jpg ...
```

* 模板里没有 `{n}` / `{page}` 这类唯一占位符时，重名的自动加后缀：`页.jpg`、`页-2.jpg`、`页-3.jpg`……
* 文件名里不能用的字符 `\ / : * ? " < > |` 会自动换成下划线，首尾的空格和点会去掉。
* 交互模式下也可以直接输入一行 `--name 周例会`，效果和走菜单一样；
  输入 `--name` 回车 = 恢复默认的 `1组`、`2组`……
* 选好的名字记在 `%TEMP%\pdfsplit_nametpl.txt`，下次打开窗口还在，`n` 菜单里能看到当前状态。

### 纯 Python 用法

仓库里也放了 `拆分PDF图片.py`（内容与 bat 内置的完全相同）：

```bash
pip install pillow numpy
python 拆分PDF图片.py "文件或文件夹" -o 输出目录 --name "会议纪要-{n}"
python 拆分PDF图片.py --compress --target 5 "文件.pdf"
```

## 环境

* Windows 10 / 11，`cmd` 能用即可。
* Python 3：优先用 bat 旁边的 `python\python.exe`，找不到就用系统 PATH 里的
  `python` 或 `py -3`。**每个候选都会真的执行一次 `import sys` 验证**，
  避免撞上微软商店那个“假 python.exe”。
* 依赖 `pillow`、`numpy` 第一次运行时自动 `pip install`。

## 实现要点

* **自带 Python 源码**：整个 bat 是一个文件，Python 代码嵌在 `::#>>>PY` 与
  `::#<<<PY` 之间，运行时由 PowerShell 解包到 `%TEMP%` 再跑，收尾删除临时文件。
* **cmd 部分保持纯 ASCII**：cmd 在部分区域会按 GBK 解码 UTF-8 的批处理行，
  中文注释会被切碎当成命令执行（报 `'xxx' 不是内部或外部命令`），
  严重时窗口直接消失。所以中文界面全部由内置 Python 打印。
* **极简 PDF 解析**：不用 pypdf 之类的第三方库，直接扫 `obj`、`stream`、
  页树 `/Contents` 里的 `Do` 指令，按绘制顺序拿到图片对象；遇到对象流式 PDF
  读不到页树时，退化为按对象顺序扫描所有 `/Image`。
* **路径容错**：窗口里拖进来的路径先写进清单文件再交给 Python，
  空格、`&`、`(` `)` 都不会打断；清单编码自动识别 UTF-8 / GBK。
